**Upgrade notes:**
- The bundled core stays at 0.83.2 and the control-plane protocol at 54.
- Nothing is cleared; the request history, stored payloads and settings carry over.

**Global shortcut:**
- Ctrl+Alt+H (Control+Option+H on macOS) opens the main window from any app. Pressing it again while the window is in front closes it.
- Settings > General > Global shortcut records another combination, turns the shortcut off, or restores the default. A combination must include Ctrl, Alt or Cmd (Win or Super on Windows and Linux), except F1 to F12. Shortcuts the app already uses inside its window cannot be chosen.
- If another app already uses the combination, it is not saved and the row says so.
- The shortcut is kept on each computer and is not synced.
- On macOS, the menu bar's Open ThinkWatch Lite item shows the shortcut.
- Linux Wayland sessions do not support global shortcuts; the row is unavailable there.

**Main window:**
- The main window opens at the same size at every interface size, instead of growing with it. It grows only when 150% needs a larger minimum size.
- The main window opens in the middle of the screen every time.
