**Upgrade notes:**
- The bundled core is now 0.72.0, with control-plane protocol 47 as before. A remote server on core 0.71.0 or 0.72.0 keeps working.
- Nothing is cleared; the request history, stored payloads and settings carry over.

**Fixed:**
- A tool call whose arguments had a URL right after a non-ASCII character, such as Chinese text followed by a full-width colon and a link, no longer ends the answer early. Tool-call inspection, on in observe mode by default, crashed on such text while the answer streamed: Codex reported `stream disconnected before completion`, and the request was recorded as interrupted by an error inside the gateway.
- When the gateway's own code fails during a request, the request's error now says what failed and where, instead of only that the request was interrupted.

**Outbound redaction (Replace mode):**
- A private key echoed in an answer comes back with real line breaks instead of `\n`.
- A value inside a tool call's arguments is put back so the arguments still parse, in streamed and whole answers, replays and WebSocket connections.
- Codex's freeform tool input, such as `apply_patch`, is restored while it streams, and over WebSocket a placeholder cut across two messages is restored.
- A stored request shows the placeholder the upstream received, also when the client wrote the value with escapes such as `\u00e9` or `\/`.
