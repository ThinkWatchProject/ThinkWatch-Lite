Traffic tables now keep token usage and cost visible in narrow windows. Model, key and upstream names shrink before the table scrolls horizontally, while numeric columns retain enough space for their values. Hovering a shortened name reveals the full text. Safety and format-conversion badges remain readable.

The existing column settings now support pinning columns to the left or right. Pinned columns work consistently in request rows and session summaries, with matching hover and selection colors. When the window is too narrow for all selected pinned columns, the table temporarily reduces the fixed area and restores it when space is available. Clicking a request continues to open the existing detail drawer.

Saved column visibility and relative order are preserved. Existing layouts automatically gain right-pinned token and cost columns when both are already the last visible columns; custom layouts and explicit unpinning are respected. Column preferences remain local to each installation.

This release continues to bundle Core 0.89.2. The control-plane protocol remains 58 and the request-store schema remains 28. Existing settings, upstreams, request history and usage history are kept.
