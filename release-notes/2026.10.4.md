**Upgrade notes:** the bundled core stays at 0.61.0, so a remote server running 0.61.0 keeps working with this version and nothing on the server has to change. Request history is kept.

**Linux: no more blank window on newer distributions:**
- The AppImage no longer carries its own Wayland libraries. It used to bring those of the system it was built on (Ubuntu 22.04), loaded ahead of the system's, and on distributions with a newer graphics stack, such as Arch, the window could stay blank. The app now uses the system's Wayland libraries, which every Linux desktop has.
- On a Wayland session the app now runs on Wayland itself instead of through X11 (XWayland).
- Thanks to [sunnysab](https://linux.do/u/sunnysab) on LINUX DO, whose work packaging the app showed the fix.

**Under the hood:** Tauri 2.12.1.
