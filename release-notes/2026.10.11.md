**Upgrade notes:**
- The bundled core is now 0.67.0, with control-plane protocol 43. A remote server must be upgraded to core 0.67.0 together with the app: this version does not connect to a server on 0.66.0, and 2026.10.10 and earlier do not connect to 0.67.0.
- **The request history and stored payloads are cleared on the first start.**
- The failover settings for a slow-starting stream are replaced by the no-response timeout. A configuration that still has `failover.next_on_slow_start` or `failover.stream_start_wait_secs` makes the gateway start in safe mode; the repair it offers deletes them.
- Requests converted for Claude now use prompt caching: cache writes are billed at the cache-write rate and reads at the much lower cache-read rate, and both are priced and shown with the request.

**No response and abort:**
- **Settings › Failover** has a **No-response timeout**, 300 seconds by default. When an upstream sends no content for that long, the request moves to the next upstream; when none is left, the client gets a timeout error instead of waiting indefinitely. After an answer has started, it ends with an error the client understands. Keep-alive pings do not count as content. It replaces the switch for moving on when a stream is slow to start.
- A running request can be stopped with **Abort request** in its menu on the Traffic page, and every running request of a session with **Abort session**. The request's details show **Aborted** or **No response** with the time waited.

**Codex:**
- Through a route that converts to Claude, GLM, DeepSeek or another format, Codex keeps all its tools. For some models Codex declares its tools in a way that was dropped, and it then reported that it could not read files or run commands. Its history, compaction of long sessions and instructions in the middle of a conversation also arrive now.
- Requests converted for Claude are cached, so the turns of a long session cost much less.

**Upstreams:**
- Models can also be added by hand in an upstream's dialog, in **Models**, for any upstream and while creating one. They are marked **Manual** and saved with the upstream.

**Traffic:**
- Long upstream, model and key names no longer widen the table: they are cut with an ellipsis and shown in full on hover, also in the row menus.

**ChatGPT account:**
- Signing in on another device works again. OpenAI changed the format of a value in its sign-in answer, which stopped the sign-in with an error.
