ThinkWatch Lite restores existing windows more reliably from the tray, including minimized windows on KDE Wayland. Opening the main window or navigating from the tray keeps the existing webview and unsaved form contents. Update notices restore the update window, and background tray actions leave the current window focused.

- Linux uses the desktop's StatusNotifierItem and DBusMenu protocols directly, passing each activation token to the window requested by that action. The tray remains available after a panel restart, and menu changes invalidate old actions so stale clicks cannot target a different item.
- Wayland activation depends on the desktop supplying a token. The Plasma 6.6 branch supports tokens for menu items; older desktops may supply them only when clicking the tray icon. Click the tray icon to open the main window on those desktops.
- Window restoration on Windows preserves maximized windows. Shortcuts and update notices use the same restoration path as the tray.

This release continues to bundle Core 0.89.1. The control-plane protocol remains 58 and the request-store schema remains 28. Existing settings, upstreams, request history and usage history are kept.
