**Upgrade notes:**
- The bundled core is now 0.75.0. The control-plane protocol stays at 48, so remote servers on core 0.74.0 keep working.
- Nothing is cleared; the request history, stored payloads and settings carry over.
- Plugins: changes a hook makes to the request or tool call it receives now take effect without returning it. Before, they were dropped unless the hook returned the object. The two built-in plugins are updated unless their code was edited.

**Security:**
- The dangerous-command check now looks at every choice of a streamed Chat Completions answer and every candidate of a Gemini answer, not only the first. An upstream could otherwise get a tool call past the check by placing it in a second choice, or by spreading its arguments across two choices.
- In a streamed answer with several choices, placeholders are restored in each choice separately; the choices could get mixed before.

**Plugins:**
- Plugins have a global `tw` with helpers for common edits: `tw.appendSystem`, `tw.texts`, `tw.toolCalls`, `tw.mapStrings`, `tw.replace`, `tw.streamReplace`, `tw.lines` and `tw.pairs`. `tw.streamReplace` replaces text in streamed answers, including a match that spans two pieces of the stream. The template for a new plugin uses them. See the Plugins page of the documentation.
- A stream-mode plugin that held back text and cut a placeholder in two left the placeholder in the answer instead of the original value. This is fixed.
- A stream-mode plugin that failed and was skipped could lose or reorder the text it was holding. This is fixed.
- In answers with several choices, plugins keep each choice apart, and every choice of a non-streamed answer goes through them.
- A stream-mode plugin that only holds text back, without changing it, is no longer recorded as having changed the answer.
