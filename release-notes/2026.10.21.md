**Upgrade notes:**
- The bundled core stays at 0.74.0 and the control-plane protocol at 48. Nothing is cleared; the request history, stored payloads and settings carry over.

**Upstreams:**
- In Edit upstream > Models, the context window and price cells open the existing dialogs. An unknown context window offers Set, which opens Model specs; an unpriced model offers Set price, which opens the price sheet dialog. Models that are not enabled can be set up too.
- Each model row has a menu, from the "..." button at the end of the row or a right-click: Specs, Set price, Add alias, and Remove for models added by hand. Aliases that list a model are shown after its name.
- Below the model table, a line counts the enabled models whose context window is unknown; clients that are taken over use their own default for those. The note about unpriced models has a Set price button.
- Set price works like the one in Billing. On the default price sheet it creates a new sheet named after the upstream, and the upstream uses it from then on, so the next Set price edits that sheet; on a custom sheet it adds the model as an override.
- In the upstream list, the model count shows a dropdown arrow. The model popover marks unpriced models and unknown context windows, has the same row menu instead of buttons that only appeared on hover, and its footer link is now Manage models.

**Traffic:**
- In a request's Content tab, a streamed answer now stays on screen when the request ends, until the stored copy has been written. It could show as not saved until the request was opened again.
