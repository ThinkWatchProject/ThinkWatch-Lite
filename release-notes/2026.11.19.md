This release bundles Core 0.98.1, which improves request-body handling when several large or compressed requests arrive together.

- Requests wait for memory in order. Decompression releases partial output before waiting for exclusive memory and retrying once, avoiding stalled requests under memory pressure.
- Memory waits and stalled uploads are bounded to 30 seconds. A request that still cannot obtain memory returns the existing retryable 429 response.
- In **Routing → Auxiliary → Web tools → Test**, press Enter in the query, URL or pattern input to run a test. Confirming an input-method candidate does not submit the request.
