- From an upstream model's menu, choose **Add alias…** to create an alias or add the model to an existing one. The model is appended to the list. Preview which model each upstream will receive before saving.
- When configuring a route with **Specific upstream models**, select an upstream and search by alias to find its model ID. Selecting a result pins that ID. You can also enter an ID manually. To have the route follow future alias changes, choose **Upstream or group** and enter the alias under **Change model to**.
