Model capabilities are discovered automatically, with manual overrides available in the existing Model specs dialog. When an upstream or relay omits capability metadata, choose supported reasoning effort levels and an optional default yourself, explicitly mark effort as not adjustable, or restore automatic discovery at any time. Providers without model listings can still use manually entered model IDs.

The dialog shows upstream declarations, the saved effective profile, its source, and any levels unavailable through the current protocol. Aliases offer only levels supported by every routing candidate. Sharing links now disclose when they omit manual effort profiles and recommend a config package instead.

This release bundles Core 0.95.0. After updating, restart Codex to reload its model catalog.
