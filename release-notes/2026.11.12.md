This release bundles Core 0.94.0, fixing Codex reasoning-effort discovery for upstreams that report model capabilities, including DeepSeek. Supported effort levels and defaults are read from the upstream and exposed through the gateway model catalog. Model aliases inherit the capabilities of their actual routing targets; aliases with multiple targets expose only the reasoning levels all targets support.

After updating Lite, restart Codex to reload its model catalog. Upstreams and relays must supply and preserve the capability metadata for reasoning choices to appear. Manual model settings remain effective. No model-name capability table or database migration is required.
