**Upgrade notes:**
- The bundled core is now 0.66.0, with control-plane protocol 42. A remote server must be upgraded to core 0.66.0 together with the app: this version does not connect to a server on 0.65.0, and 2026.10.9 and earlier do not connect to 0.66.0.
- Request history is kept.
- Models added by hand are now checked when the configuration loads. An entry with `*` or `?`, spaces around it, a duplicate, or more than 256 characters is refused and the gateway starts in safe mode, naming the upstream and the model; the earlier manual model list accepted such entries. Plain model ids load unchanged.

**Upstreams:**
- Models can be added by hand: **Add models…** in an upstream's model list. A model the upstream serves but leaves out of its list — newer models an account backend hides, a relay that lists only some — is then routed to it like any listed model: routing and failover, aliases, routing rules that name a model, a key's allowed models, the model list clients see, the dry run and the speed test.
- Models added by hand are marked **Manual** and can be removed from the list, with **Undo** in the confirmation. The summary counts them apart from the ones the upstream lists. For an upstream that lists no models, the same dialog replaces the manual model list.

**Menu bar:**
- The **Menu bar** setting has a fourth choice, **Hidden**, which takes the item off the menu bar. Opening ThinkWatch Lite again from Finder or Spotlight shows the main window; the gateway keeps running in the background.

**MCP:**
- Editing a client's configuration, such as adding a line to `~/.codex/config.toml`, no longer reports the remote MCP servers and other findings that were already there as new. Only findings that are actually new are reported.
