**Upgrade notes:**
- The bundled core stays at 0.70.0, with control-plane protocol 46. A remote server on core 0.70.0 keeps working.
- Nothing is cleared; the request history, stored payloads and settings carry over.

**New upstream:**
- Every step of the dialog fits the default window without scrolling; only long lists such as the model table scroll in their own box.
- The first step lists services in four columns, with the search box beside the steps.
- ThinkWatch, Sub2API and New API / One API take an API key only; OAuth remains for custom services. An existing upstream that already uses OAuth keeps it.
- Request headers, client identity forwarding, the behaviour when the proxy is unavailable and the concurrency limit are under **Advanced settings**, collapsed unless one of them is set.
- **Next** checks the connection. When it passes, the **Models** step opens with the result on top: latency, the number of models found and the balance where the service reports one. When it fails, the step stays open with the reason, **Retry** and **Continue anyway**.
- Signing in with a ChatGPT account offers two methods side by side: the browser, where the sign-in link can also be copied, and a device code. For Z.ai / BigModel, the method and the site share one row, and BigModel (mainland China) is listed first and selected by default.
- After signing in, the dialog goes straight to **Models**, with the account on top; a ChatGPT account also shows its tightest quota window. Back on the account step, the signed-in account has **Sign in again**.

**Editing an upstream:**
- The dialog uses the same layout and rules. **Check connection** sits at the left of the footer, with its result beside it.
