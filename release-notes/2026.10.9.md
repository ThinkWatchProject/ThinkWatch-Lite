**Upgrade notes:**
- The bundled core is now 0.65.0, with control-plane protocol 41. A remote server must be upgraded to core 0.65.0 together with the app: this version does not connect to a server on 0.64.x, and 2026.10.8 and earlier do not connect to 0.65.0.
- Request history is kept. The first start adds indexes to the request store, which takes about a second on a large history.

**Menu bar and tray menu:**
- **Open ThinkWatch Lite** is always the first item, whatever else the menu shows.
- A **Today** block replaces the header and the three large numbers: today's tokens in large type, requests, failures and cost below them, and a small chart of tokens per hour. Its top line shows the gateway state and the generation speed, and the server's name when connected to a remote core.
- One row per quota window the upstream reports, with when it resets.
- **Copy Gateway Address** shows the address it copies. **Install Version** is the first item of its group when a new version is available.

**Faster:**
- The Traffic page opens in a fraction of the time with thousands of requests in the list, uses far less memory, and stays smooth while requests arrive.
- The launch screen appears after a small part of the app has loaded; pages load as they are opened.
- Live updates and the Overview chart use less CPU, and nothing is redrawn while the window is hidden or minimised.
- The gateway processes large requests about four times faster, and no longer pauses other answers that are streaming at the same time.
- The conversation view of a long session fetches only the new turns instead of the whole conversation each time.
- On macOS, watching the clients' configuration files no longer wakes the app for every file change in the home folder.
- Over a remote connection, the Overview's figures are fetched in parallel.

**Fixes:**
- Forwarded request bodies keep the client's bytes and key order. Removing `metadata.user_id`, and a routing rule or alias changing the model, output limit or thinking, used to rewrite the body with every object's keys in alphabetical order.
- When one day's stored payloads exceeded the size cap, the hourly clean-up deleted that whole day, including the session being viewed. The current day now loses only its oldest payloads.
- Sessions older than the newest 500 open again.
- The **Configuration file** and **Version history** dialogs show an error with **Retry** when they cannot load, instead of loading forever.
- If the menu bar item, tray icon or a window cannot be created at startup, the app reports it as a notice and keeps the gateway running, instead of quitting.
- The routing dry run shows each round-robin member's share as the gateway computes it; members sitting the round out show none.
- On Windows, the ring around an in-progress request's status dot now animates.
- Numbers are written the same way everywhere: latency as `1182ms`, dates as `10-08`, token counts as `1.5k`.
