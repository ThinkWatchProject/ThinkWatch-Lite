ThinkWatch Lite now bundles Core 0.89.1. ChatGPT account quotas populate automatically after startup and update in Overview and the menu dropdown without opening the Upstreams page.

- Core refreshes quotas when an account is first discovered, after 15 minutes without a fresh quota update, or after a reported quota window resets. Quota headers from real traffic postpone background queries. Concurrent reads share work, automatic queries are limited to four accounts at a time, and failures back off while retaining the last known quota. No configuration changes are required.
- Overview listens for quota updates and refreshes automatically when background queries finish. Manual usage refresh remains available.
- Pi and omp takeovers preserve `xhigh` and `max` reasoning effort instead of reducing them before requests reach the gateway. OpenCode exposes all six gateway effort levels through explicit variants in both configuration formats, including early v2 releases. Existing takeovers with incomplete effort declarations are flagged for update; updating retains the original restore backup.

The control-plane protocol remains 58 and the request-store schema remains 28. Existing settings, upstreams, request history and usage history are kept. Remote connections continue to work with protocol-58 servers; upgrade a remote Core to 0.89.1 to enable automatic quota refresh there.
