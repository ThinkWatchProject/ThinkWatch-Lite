**Upgrade notes:**
- The bundled core is now 0.69.0, with control-plane protocol 45. A remote server must be upgraded to core 0.69.0 together with the app: this version does not connect to a server on 0.68.0, and 2026.10.12 and earlier do not connect to 0.69.0.
- Nothing is cleared; the request history, stored payloads and settings carry over.

**Upstreams:**
- **New upstream** starts with a **Service** step: a searchable grid in two groups, sign-in accounts (ChatGPT, Z.ai / BigModel) first, then API access (Anthropic, OpenAI, Google Gemini, Amazon Bedrock, DeepSeek, Ollama and Custom). Picking one goes straight to **Connection**, where the name, address and protocol are already filled in; the dialog's title shows the choice, and **Back** returns to the grid with it marked.

**Routing:**
- Rules can match the **time of day**: a weekday picker and a start and end time make one window, a rule can hold several, and a window may run overnight. The gateway evaluates it in the local time of the machine the core runs on; the dry run names the time it saw when the condition did not match.
- On the routing map, each request in flight moves along its whole path in a colour of its own, so two requests on the same edge stay apart.

**Sessions:**
- Every turn of a session shows how full the model's context window was: the input tokens over the window, with cache reads as their own segment. Opening a turn shows an estimated breakdown into the system prompt, the tool definitions, the earlier history and the last user message; when the request body is no longer stored, the turn says so.

**Warnings:**
- Every amber warning can be ignored: each line of the overview's **Needs attention** strip, the notice that request recording could not start, the lost-connection banners and the config-rejected banner. An ignored item returns when it has news (a newer failure, one more upstream down, a different config error); **Show again** in Settings › General brings them all back, together with the guidance hints.

**Menu bar:**
- The menu bar item no longer turns orange or red for a tight or exhausted quota; the quota windows inside the menu keep their colour, and the hover text still names the tightest window.

**Gateway (core 0.69.0):**
- A model's reasoning survives format conversion: a Chat-format upstream's `reasoning_content` (DeepSeek, Kimi, GLM) is sent back to that upstream on the next turn, and a Gemini model's thought signature on a function call is kept through Anthropic and Responses clients.
- Tool calls that a Chat-format model writes into its answer text (`<tool_call>` blocks, DeepSeek's and GLM's own forms) are recognised and delivered as ordinary tool calls when the request defined tools; they go through tool-call inspection like any other.
- Request bodies sent compressed (gzip, deflate, zstd) are read on every route, and compressed upstream answers reach the client decoded.
- A streamed request waiting for its key's concurrency slot or rate window receives keepalives after 15 seconds, as one waiting on an upstream already did, so clients no longer time out while queued.

**Removed:**
- Notices about things the gateway handles by itself: the account box no longer says when a credential expires and renews, and a refresh token written back successfully no longer raises a banner. Only a failed write-back is reported.
