**Upgrade notes:**
- The bundled core is now 0.64.1. The control-plane protocol stays at 40: this version connects to a remote server on 0.64.0 or 0.64.1, and 2026.10.7 connects to 0.64.1.
- Request history is kept.

**Gateway:**
- Requests over 2 MiB are no longer refused. A conversation holding a few inline screenshots passed 2 MiB and was refused with 413 from then on, compaction requests included, so the session could not be compacted back under the limit. The gateway's limit is now its intended 256 MiB.
- A request over the limit is answered with 413 in the client's own error format. A request's body is read only after its source address and key are checked.

**Updates:**
- A new version found by the daily check is listed in the notices, in grey, and shown as a system notification when notices are set to that. Before, it was a one-off system notification, and once it was dismissed only the menu item was left. Clicking the notice opens the update window. Finding a newer version replaces the notice for the older one.
