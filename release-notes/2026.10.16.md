**Upgrade notes:**
- The bundled core is now 0.70.1, with control-plane protocol 46 as before. A remote server on core 0.70.0 or 0.70.1 keeps working.
- Nothing is cleared; the request history, stored payloads and settings carry over.

**Import links:**
- An import link now opens the **New upstream** dialog with its settings filled in, on the connection or account step, instead of a separate confirmation dialog. Every setting can be reviewed and changed before **Create**.
- A link can set what the dialog sets for every service type: the service, the authentication method, the address, protocol and key, OAuth and AWS access keys, request headers, client identity forwarding, the concurrency limit, the balance source, models added by hand, the enabled models, model specs, the billing mode and prices. A link for a ChatGPT or Z.ai / BigModel account carries no credentials and opens on the sign-in step.
- A link cannot set the outbound proxy, an AWS profile, environment variables, aliases, routes or the default upstream. Authentication headers are refused.
- Every step names the host that will receive requests and the key. Nothing is written and nothing is sent until **Next** is chosen on the connection step or a sign-in is started.
- A link with a parameter this version does not know shows **Cannot import this link**, with **Check for updates**. Links made for earlier versions work as before.
- Plain `http://` addresses on a private network, such as a company's ThinkWatch Enterprise gateway, are accepted; the dialog notes that they are not encrypted. ThinkWatch Enterprise 3.6.0 adds **Add to ThinkWatch Lite** next to a new key.

**Upstreams:**
- A custom upstream has **Balance source** under **Advanced settings**.
- Steps with many settings scroll instead of being squeezed: when editing, **Check connection** is back in the connection section with its full result; advanced settings, OAuth and AWS fields and the ChatGPT account page are laid out in their natural order again, and the hints under the base URL, headers, session token, access token and outbound connection are back.

**Plugins:**
- With every plugin disabled, the plugin list again shows each plugin's name, description, permissions and settings after an upgrade, not only its file name.
