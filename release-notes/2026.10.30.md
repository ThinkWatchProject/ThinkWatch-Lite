**Upgrade notes:**
- The bundled core is now 0.83.2. The control-plane protocol stays at 54, so remote servers running core 0.83.0 or later stay connected.
- Nothing is cleared; the request history, stored payloads and settings carry over.

**Fixes:**
- Since 2026.10.25, changing any setting while sync was off or could not be set up (for example renaming a client or adding an upstream) left the core using a full CPU core in the background until it was restarted. The core now stays idle.
- When the control plane cannot accept a connection, for example after running out of open files, it waits a second before trying again instead of retrying at once and filling the log.

**Menu bar:**
- The two-line numbers in the menu bar use a medium weight, so they read as dark as other menu bar readouts.
