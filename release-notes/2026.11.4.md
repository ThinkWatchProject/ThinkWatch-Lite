Traffic columns can now be hidden and reordered, with a compact preset that keeps model, token and cost information visible in smaller windows. Preferences are saved locally and apply to request rows and session rows. Older records display their date and time on separate lines.

Request rows show the model name sent to the upstream, with the original requested name underneath when routing changes it. Both lines share the existing width limit, and hovering reveals the complete names. Credential names align with the column heading, with recognized application icons placed after the name.

HTTP record details now explain when stored headers and bodies are redacted. The decoded view and raw view use consistent labels so a redacted archive is not mistaken for an exact wire capture.

This release bundles Core 0.89.2, which reduces credential false positives in code and pool logs, enables native system proxies for upstreams configured to use them, and preserves Mistral array response fragments and split placeholders during format conversion. Applying or reloading configuration refreshes system proxy settings. The Mistral fixes cover reproduced compatibility defects; the original report of delayed or truncated output still needs confirmation with complete traffic.

The control-plane protocol remains 58 and the request-store schema remains 28. Existing settings, upstreams, request history and usage history are kept.
