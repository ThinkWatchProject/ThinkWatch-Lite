This release bundles ThinkWatch Core 0.98.0 with improved free web search. Core connects directly to Google (Docs), DuckDuckGo and Bing, without API keys or a browser runtime.

- Automatic search follows Core's recommended order: Google (Docs), DuckDuckGo, then Bing. Cached results, shared concurrent searches, per-engine pacing and cooldowns reduce repeated requests and allow another source to take over when one fails.
- The search engine picker reads the connected Core's capabilities. Google (Docs) can be selected and saved alongside other sources, with readable engine names in test results. Connections to older Core versions retain their existing choices.
- Google (Docs) searches public web pages through a legacy Google endpoint, with at least six seconds between requests and no regional preference support. It depends on the endpoint and eligible public document contexts remaining available.
- The native bridge preserves new search engine identifiers while Core continues to validate configuration and search requests. Other control-plane routes keep their existing validation.

Configure and test these sources under **Routing → Auxiliary → Web search and page reading**. Existing upstream execution settings remain unchanged until Core execution is enabled.
