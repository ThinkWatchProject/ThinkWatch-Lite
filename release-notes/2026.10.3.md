**Upgrade notes:**
- The bundled core is now 0.61.0, which speaks control-plane protocol 37. A remote server has to run core 0.61.0 too: this version does not connect to 0.60.0, and 2026.10.2 and earlier do not connect to 0.61.0.
- Request history is kept.
- If 2026.10.2 showed "core is not running" after the update because `config.yaml` still set `passthrough` or `route` under `client_probes:`, this version shows the line at fault and repairs it in one click.

**Configuration errors:**
- When core cannot read `config.yaml`, the app shows the file, the line, the reason and the line itself, instead of "core is not running". Core runs in safe mode: client requests are not forwarded, and the configuration can still be edited and rolled back.
- One-click repair: a value outside its choices goes back to its default, and an unknown field is removed. The changes are listed before they are made, and the previous version is kept in Version history. The same repair is offered when an edit to the file is refused while the gateway keeps running on the previous version.
- Once a working configuration is saved in safe mode, the gateway starts forwarding again on its own.
- A value outside its choices and a misspelled field, the two commonest mistakes, are described in the interface language.
- When core still cannot start, the app shows the reason core gave.
