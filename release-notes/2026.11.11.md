Lite now detects missing or incorrect settings in managed Codex connections and shows an **Update configuration…** action on the Clients page. This includes connections created before gateway model discovery was added, as well as configuration changes made afterward.

The check reads the current configuration, including the selected profile, and works without fetching a gateway model list. Both local and WSL connections are covered. Previous successful requests no longer hide a configuration problem.

After upgrading, open **Clients**, review and apply the proposed configuration update, then restart Codex. There is no need to disconnect first or edit `config.toml` by hand. The updated connection uses the gateway's native model catalog for available models and their metadata. Changes are written only after confirmation, and the original restoration state is retained.

This release continues to bundle Core 0.93.0. No database migration is required.
