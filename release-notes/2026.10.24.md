**Upgrade notes:**
- The bundled core is now 0.76.0 and the control-plane protocol is 49. A remote server running an older core must be upgraded to 0.76.0 to stay connected.
- Nothing is cleared; the request history, stored payloads and settings carry over.

**Live generation speed:**
- The menu bar's second line shows how fast the running requests are generating right now, added together, and updates every second while requests run. It shows 0 t/s while requests wait for their first token and a dash when nothing runs. Before, it showed the speed of requests that had finished in the last minute, so a long request showed a dash until it ended.
- Each row under In Progress in the menu shows that request's current speed next to its running time.
- On the Traffic page, a running request shows its current speed in the token column until it finishes.

**Other:**
- An upstream that hangs up in the middle of an answer is reported as a broken connection with its cause, instead of "error decoding response body".
