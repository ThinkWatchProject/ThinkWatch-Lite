Standard controls throughout ThinkWatch Lite now use the shared shadcn UI components, providing consistent selection, keyboard navigation, dialogs, tabs, and tables.

Web search and page reading are shown in the same table as other auxiliary requests under **Routing → Auxiliary**. Search language and country/region menus can now be scrolled and selected inside dialogs. Allowed and blocked domains are separate editable lists with validation, duplicate removal, and support for pasting multiple entries.

Choose **Automatic** or multiple specific search engines in a single dropdown. Automatic and named engines are mutually exclusive; removing the last named engine restores Automatic. Saved engine selections and their order are preserved. Search menus support keyboard input and close before the enclosing dialog when Escape is pressed. Configuration forms remain scrollable above the Save and Cancel buttons in compact windows.

This release continues to bundle ThinkWatch Core 0.97.0.
