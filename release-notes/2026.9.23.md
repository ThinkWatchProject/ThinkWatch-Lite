**Upgrade notes:** the bundled core stays at 0.54.0, so a remote server running 0.54.0 keeps working with this version and nothing on the server has to change. Request history is kept.

**Updates keep the window as it was:** after an update, the app comes back the way it was before. If it was running in the menu bar only, it stays in the menu bar; if its window was open, the window opens again. Before, the main window opened after every update. This applies to updates the app installs itself, on every platform, and to `brew upgrade` on macOS. A Homebrew upgrade now also shows the "Updated to …" notification when Notices is set to System notification.

The update from 2026.9.22 to this version is not covered yet: 2026.9.22 does not record the window when it quits, so this one update still opens the window and shows no "Updated to 2026.9.23" notification.

**Sidebar:** with the sidebar expanded, hovering a page no longer pops up a tooltip that repeats its name. The page's shortcut (⌘1 to ⌘9, or Ctrl+1 to Ctrl+9 on Windows and Linux) appears at the end of its row while the pointer is over the row or the row has keyboard focus. The collapsed sidebar still shows the name and the shortcut in a tooltip.
